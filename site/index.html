琉璃启动器

LAZULI LAUNCHER
琉璃启动器是一款 Minecraft Java 版启动器，支持 Windows 桌面与 Android 手机两个平台。
内置微软正版登录与离线登录、版本管理、模组下载、Fabric 加载器一键安装、皮肤预览。
手机版内置 JRE 与图形转译层，可在安卓设备上直接运行 Java 版游戏。
